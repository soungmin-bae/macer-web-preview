Reference database · CRD / PhononDB

CRD references are calculated DFT data, not experiments. Search by Materials Project ID or formula, then confirm the exact phase before loading. Bundled records are limited to 3D structures with at most 6 atoms; other matches are listed as unavailable.

CRD v1.0.1 · curated local reference records · CC BY 4.0.

Source and attribution

Overlay is enabled only when the completed calculation matches the reference cell, periodic atom positions, elements, and masses. Curves use the same FWHM but are normalized separately; no temperature/laser prefactors or absolute-intensity comparison. Missing tensors stay missing. Animate reference modes only.

Open a PhononDB reference

Download a record from NIMS MDR, then open its phonopy_params.yaml.xz or decompressed YAML file here. Decompression runs locally in this browser. Source force constants are used directly, or displacement forces are used to reconstruct them; no model forces are evaluated.

The license entry is a user attestation; the app does not verify NIMS metadata. Imported NAC data, if present, is not applied to these reference bands.

Polarized Raman · tensor calculator

Postprocess supplied Cartesian tensors. Sample rotation in backscattering;crystal Cartesian rotation axis and perpendicular zero-angle direction define the initial laboratory frame. No new forces or model inference.

Parallel and crossed traces use one common scale. Degenerate components add intensities,not amplitudes. Channel mixture has no unique tensor and is unsupported here. Changing laser wavelength does not calculate electronic resonance. Frequencies and tensor accuracy remain those of the selected model or reference.
