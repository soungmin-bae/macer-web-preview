# CRD browser reference subset

This folder contains selected structure, Γ-mode, and Raman-tensor records from the Computational Raman Database (CRD), release v1.0.1. The source archive SHA-256 is `1a03a98877643584ab0139f06879c8668962f89bf8709884751f3bdbdc36c4a4`. Records are redistributed under CC BY 4.0 with their original material IDs and attribution links. Unbundled records are not fetched from a remote proxy.

Authors: Mohammad Bagheri and Hannu-Pekka Komsa. Cite: M. Bagheri and H.-P. Komsa, Scientific Data 10, 80 (2023), https://doi.org/10.1038/s41597-023-01988-5. Source: https://ramandb.oulu.fi/ . License: https://creativecommons.org/licenses/by/4.0/ .

This subset is a calculated reference dataset, not experimental spectra. Mode/tensor data are preserved per source record; missing tensors remain missing.
