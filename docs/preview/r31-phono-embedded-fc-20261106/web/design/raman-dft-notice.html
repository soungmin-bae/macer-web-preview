DFT relative Raman profile · experimental

This small model estimates relative powder peak strengths from the structure and existing analytic Γ eigenvectors. It does not produce a single material Raman tensor, absolute intensity or polarized spectrum. It does not change phonon frequencies.

Measured limitations

On 100 new composition-disjoint materials, 92 were supported and 8 explicitly rejected for insufficient element coverage. Supported-only median normalized-activity L1 improved from geometric BPM 1.497 to 0.576; the ≤0.50 goal remains failed. Reserved anatase regressed. Agreement with experiment is unqualified. A model trained on DFT is still an approximation.

Model 46,712 bytes, active IR + Raman 204,952 bytes. Actual single-session browser warmed 36-atom response median 34.1ms. This is not whole-phonon acceleration or three-browser qualification.
